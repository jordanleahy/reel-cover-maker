Reel Cover Maker — standalone web app

Host this folder on any static host (all files at the same level):
  - Netlify Drop: drag the folder onto https://app.netlify.com/drop
  - Vercel, GitHub Pages, Cloudflare Pages also work
It must be served over https (not opened as a local file) for the
home-screen install and share sheet to work.

On iPhone: open the URL in Safari → Share → Add to Home Screen.
"Save cover" opens the share sheet → tap "Save Image".
